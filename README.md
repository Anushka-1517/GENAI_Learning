
# Generative AI Learning Journey 🤖

This repository documents my hands-on learning journey in Generative AI, exploring Large Language Models (LLMs), LangChain, and the development of practical AI applications using different LLM providers and tools.

## 🚀 What I've Learned

### Prompt Engineering
- Static and dynamic prompts
- System and user prompts
- Prompt templates
- Using variables inside prompts

### LangChain
- LangChain fundamentals
- ChatPromptTemplate
- Prompt chains
- Connecting prompts with LLMs
- Working with multiple LLM models
- Creating and invoking LangChain tools
- Integrating language models with external tools

### Large Language Models (LLMs)
- Working with different LLM providers
- Calling LLMs through LangChain
- Understanding model invocation
- Handling model responses
- Integrating Google Gemini and Groq models

### Tokenization
- Understanding tokens
- Token counting
- How text is converted into tokens

### AI Applications

#### AskBuddy – AI Q&A Bot
- Built an AI-powered Q&A chatbot using Python, LangChain, Google Gemini, and Streamlit
- Integrated an LLM to generate answers to user questions
- Implemented an interactive chat interface with session-based chat history

#### Google Search AI Agent
- Learned the fundamentals of AI agents and how they work
- Built AI agents using Python and LangChain
- Created an agent using LangChain, Groq, and Python
- Integrated Google Search using the Serper API
- Used LangChain's `create_agent()` to build a tool-enabled AI agent
- Configured system prompts and processed user queries
- Built an interactive command-line interface with a welcome message and exit command
